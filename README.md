# TimeConverter

**TimeConverter** — Android-приложение, написанное на Kotlin, предназначенное для конвертации времени между различными единицами: секунд, минут, часов, дней, недель, месяцев, лет, десятилетий, столетий и тысячелетий.

## Основные функции

- Ввод значения времени для конвертации
- Выбор исходной и целевой единицы времени через выпадающие списки (*Spinner*)
- Моментальный расчет и вывод результата
- Поддержка основных единиц измерения времени: секунда, минута, час, день, неделя, месяц, год, десятилетие, столетие, тысячелетие
- Удобный и интуитивный дизайн на Android

## Стек технологий

- **Kotlin**
- **Android Studio** (API 24+, Android 7.0+)

## Как запустить

1. Откройте репозиторий в Android Studio
2. Соберите проект и запустите на эмуляторе или реальном устройстве с Android API 24+

## Структура проекта

- **MainActivity** — основная логика приложения, обработка пользовательского ввода, расчет и отображение результата.
- **activity_main.xml** — интерфейс: поля ввода, спиннеры выбора единиц, кнопка конвертации и поле результата.

## Пример использования

1. Введите исходное значение времени
2. Выберите единицу «Из» и «В»
3. Нажмите кнопку «Конвертировать» — результат отобразится ниже
